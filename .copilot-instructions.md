# RIOTWORKS — Project Rules (Kewajiban)

## 1. Monorepo Structure (wajib)
- Root: `Z:\project\A-L-L-A-H\MOONWITNESS\RIOTWORKS`
- `packages/ui` — shared shadcn/ui component library (`@riotworks/ui`)
- `apps/web` — Next.js App Router frontend (`@riotworks/web`)
- `pnpm-workspace.yaml` — workspace root
- `turbo.json` — task orchestrator

## 2. Package Manager
- Wajib menggunakan **pnpm** (tidak npm/yarn).
- Semua dependency baru harus ditambahkan melalui `pnpm add` di workspace yang tepat.

## 3. shadcn/ui di packages/ui
- Semua komponen UI harus ditaruh di `packages/ui/src/components/*`.
- `packages/ui` adalah satu-satunya sumber komponen shadcn/ui.
- `apps/web` hanya boleh mengimpor komponen dari `@riotworks/ui`, tidak boleh men-duplikasi komponen shadcn di dalam `apps/web`.
- `cn()` utilitas harus diimpor dari `@riotworks/ui` (via `src/lib/utils`).

## 4. Next.js App Router
- `apps/web` harus menggunakan Next.js App Router (`src/app`).
- Setiap halaman baru harus ada di `src/app/<route>/page.tsx`.
- Layout root di `src/app/layout.tsx` harus tetap memuat `ThemeProvider` dari `next-themes` dengan `attribute="class"` dan `defaultTheme="dark"`.

## 5. Tailwind CSS & Design System
- Tailwind config di `apps/web/tailwind.config.ts` harus menggunakan preset dari `@riotworks/ui/tailwind.config`.
- Palette RIOTWORKS wajib digunakan:
  - Obsidian #111315, Deep Industrial #191C1E, Panel Charcoal #24282A
  - Paper Bone #F3EBDD, Acid Lime #D2FF38, Riot Orange #FF542D
  - Electric Blue #40D9FF, Riot Pink #F047A4, Muted Ink #777A76
- Typography: Display (Archivo Black/Anton), UI (Space Grotesk), Mono (IBM Plex Mono).
- Dark mode adalah default; light mode harus dirancang terpisah (bukan invert sederhana).

## 6. TypeScript
- Semua file harus `.ts` / `.tsx`, tidak ada `any` tanpa alasan.
- `tsc --noEmit` harus lolos tanpa error di setiap package sebelum commit.

## 7. Demo Data & Prototype Boundary
- Semua data di `apps/web` adalah **demo/synthetic data**, harus ditandai jelas.
- Tidak boleh menyimulasikan publikasi, pembayaran, OAuth, atau integrasi marketplace nyata.
- Setiap aksi simulasi harus menyebutkan bahwa ini adalah prototype action.

## 8. Bahasa & Locale
- UI mendukung English dan Indonesian (toggle locale).
- Tidak ada kata "ALLAH" pada pakaian karakter atau elemen visual.

## 9. Validation Sebelum Commit
- Jalankan `pnpm install` di root setelah mengubah dependency.
- Jalankan `pnpm type-check` di root.
- Jalankan `pnpm build` di root.
- Tidak boleh ada TypeScript error, console error, atau route yang rusak.

## 10. File yang Tidak Boleh Diubah Tanpa Izin
- `pnpm-workspace.yaml`, `turbo.json`, `package.json` root — hanya boleh diubah dengan persetujuan pengguna.
- `packages/ui/components.json` — konfigurasi shadcn/ui, tidak boleh diubah secara sembarangan.
