# MOONWITNESS Brand Kit v1.2

## Master identity
MOONWITNESS is the master brand. RIOTWORKS is a separate studio identity and is not part of the default MOONWITNESS lockup.

- **Core Promise:** SEE MORE. KNOW MORE.
- **Brand Manifesto:** WHEN THE MOON RISES, WE SHARE MESSAGES. (WMR-WSM)
- **Operational verbs:** OBSERVE · RECORD · VERIFY · CONNECT · UNDERSTAND · SHARE
- **Primary mark:** lunar aperture + orbital path + witness star.
- **Primary lettering:** original outlined MOONWITNESS wordmark and MW monogram.
- **Primary lockup:** symbol + outlined MOONWITNESS wordmark + Core Promise.

## Logo files
- `assets/brand/moonwitness-symbol.svg` — primary symbol.
- `assets/brand/moonwitness-wordmark.svg` — original outlined wordmark; no font dependency.
- `assets/brand/moonwitness-monogram.svg` — original MW compact mark.
- `assets/brand/moonwitness-lockup.svg` — horizontal lockup.
- `assets/brand/moonwitness-seal.svg` — archival/editorial stamp.

Preserve proportions, keep clear space at least the width of the star detail, and do not stretch, rotate, add glow, or place over noisy backgrounds. Variants remain provisional until owner approval and target-size testing.

## Typography
The in-house type direction is **MOONWITNESS Signal**: Signal Display, Signal Text, and Signal Instrument. UI currently uses native system fallbacks; the complete WOFF2 font is still in development. See `fonts/MOONWITNESS-SIGNAL.md`.

## Palette and artwork
Import `brand-tokens.css` as a reference layer. Product themes should map primitives into semantic tokens. Original SVG artwork remains **UNLICENSED / internal project use only** until the repository owner declares an explicit license and confirms ownership/assignment.
