# MOONWITNESS Brand Kit v1.1

## Master identity

MOONWITNESS is the master brand. RIOTWORKS is a separate studio identity and is not part of the default MOONWITNESS lockup.

- **Core Promise:** SEE MORE. KNOW MORE.
- **Brand Manifesto:** WHEN THE MOON RISES, WE SHARE WHAT MATTERS.
- **Operational verbs:** OBSERVE · RECORD · VERIFY · CONNECT · UNDERSTAND · SHARE
- **Primary mark:** lunar aperture + orbital path + witness star.
- **Primary lockup:** symbol + MOONWITNESS wordmark + Core Promise.
- **Manifesto placement:** use as a supporting editorial/campaign line, not inside compact logo lockups.

## Logo files

- `assets/brand/moonwitness-symbol.svg` — symbol only; use for app icon/avatar after testing at target sizes.
- `assets/brand/moonwitness-wordmark.svg` — wordmark only.
- `assets/brand/moonwitness-lockup.svg` — primary horizontal lockup with Core Promise and a small Manifesto support line.
- `assets/brand/moonwitness-seal.svg` — archival/editorial stamp; not the primary logo.

All SVGs use controlled MoonWitness brand colors. Preserve proportions, keep clear space at least the width of the star detail, and do not stretch, rotate, add glow, or place over noisy backgrounds.

## Messaging usage

Use the Core Promise wherever the product identity needs to be immediately understood. Use the Manifesto where the human/community purpose can be given room. Avoid repeating both lines in every interface component.

## Palette and typography

Import `brand-tokens.css` as a reference layer. Product themes should map these brand primitives into semantic tokens rather than use raw brand values everywhere.

- Display: Space Grotesk 600–700 (fallback Arial).
- Body/UI: Space Grotesk 400–600 (fallback Segoe UI).
- Technical: IBM Plex Mono 400–500 (fallback system monospace).

These are family recommendations only. Font binaries are not included because font redistribution rights have not been verified.

## Artwork and texture

Original SVG assets in this package are repository-authored starting artwork. Use lunar contours and orbital grid at low opacity; keep evidence illustrations out of dense data tables. Meaningful illustrations have alt text; decorative patterns must be hidden from assistive technology.
