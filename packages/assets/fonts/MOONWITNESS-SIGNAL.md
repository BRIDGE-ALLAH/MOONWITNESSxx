# MOONWITNESS Signal — Original Typography Direction

**Status:** Original design direction v0.1; glyph system in development.

## Design intent
MOONWITNESS Signal is the working name for the future in-house type family. Its voice is observatory precision + editorial authority + lunar geometry.

## Three coordinated cuts
- **Signal Display:** condensed headlines, high x-height, open counters, squared terminals, selective 45° cuts, distinctive M/W/N geometry.
- **Signal Text:** generous apertures, stable punctuation, robust legibility at 12–18 px.
- **Signal Instrument:** tabular metrics, differentiated 0/O and 1/I/l, aligned numerals.

## Current deliverables
- The master wordmark is custom outlined vector artwork in `assets/brand/moonwitness-wordmark.svg`.
- The MW monogram is custom outlined vector artwork in `assets/brand/moonwitness-monogram.svg`.
- Product UI uses platform-native system font stacks until the full proprietary glyph set is drawn, tested, and compiled.

## Font production gate
A real WOFF2/OTF release is **not claimed yet**. Before release, create uppercase/lowercase Latin, numerals, punctuation, Indonesian diacritics; design metrics and kerning; test at 11–48 px; validate shaping and fallback; compile from editable source; record hashes; and run fontTools/OTS validation.
