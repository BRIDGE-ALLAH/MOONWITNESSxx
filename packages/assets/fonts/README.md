# MOONWITNESS typography source

The primary identity uses original vector lettering authored in this repository. The future in-house family is named **MOONWITNESS Signal** and is specified in [MOONWITNESS-SIGNAL.md](./MOONWITNESS-SIGNAL.md).

## Current state
- Master wordmark and MW monogram are custom SVG path artwork; no external font is required to render them.
- Product typography roles are Signal Display, Signal Text, and Signal Instrument.
- The current UI uses native platform stacks through `--mw-font-display`, `--mw-font-ui`, and `--mw-font-instrument`.
- Space Grotesk and IBM Plex Mono are not loaded by the product and are not identity dependencies.
- No WOFF2/OTF is claimed or shipped yet. A complete glyph family must pass the production gate in the design brief before binary delivery.

## Legacy license reference
`OFL-1.1.txt` is retained as a research record from the earlier third-party font evaluation. It does not grant MOONWITNESS ownership of Space Grotesk or IBM Plex Mono, and neither family is part of the current product font stack.
