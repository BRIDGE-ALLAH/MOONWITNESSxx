## Business and evidence terms

| Term | Meaning |
|---|---|
| Marketplace-native discovery | Buyer discovery via marketplace search, recommendations, category browsing, and platform surfaces |
| Demand Gap Mining | Finding evidence-backed buyer problems not well served by existing offers |
| Evidence item | A source-linked observation with date, provenance, and reliability |
| Evidence quality | A transparent state describing how well an item is supported |
| Product family | A set of meaningfully related products for related buyer jobs |
| Living Product | A maintained product with versions, compatibility, updates, and changelog |
| Net contribution | Receipts after relevant variable fees, refunds, and attributable operating costs, before tax unless stated otherwise |
| Payout | Cash transfer from a platform/provider to the operator |
| Provenance | Traceable origin, rights, tools, authorship, transformation, and publication history |
| Product retirement | Deliberately pausing or ending production/distribution of a product |

## Technical and operational terms

| Term | Meaning |
|---|---|
| Channel capability C0-C4 | Standardized level from research-only to tested monitored official operations |
| Hard gate | A requirement that blocks progress regardless of opportunity score |
| Idempotency | A repeated job/action does not create duplicate external effects |
| Human approval | Explicit owner authorization for a controlled action |
| Manual package | Files, metadata, instructions, and checklist for a human to submit through the platform UI |
| Official API | Documented provider interface permitted for the exact operation |
| Demo data | Synthetic prototype data, never actual revenue or account state |
| AI-generated | Content actually created by an AI tool under the applicable provider/platform definition |
| AI-assisted | Human-originated content that AI helped edit, refine, or check, subject to each platform's definition |
